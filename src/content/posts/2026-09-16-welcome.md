このブログは、GitHub Actions と OpenCode で半自動生成されるレビューブログです。

## 仕組み

- Issue に気になるページの URL と推しポイントを投稿すると記事が生成されます
- 生成された記事は Pull Request でレビューできます
- PR にコメントすると内容をブラッシュアップできます
- マージすると GitHub Pages に公開されます

## 使い方

1. このリポジトリに `label=article` を付けて Issue を立てる
2. 記事執筆の Pull Request が自動生成されるのを待つ
3. 内容を確認して `/brushup` コメントで修正を依頼
4. マージすれば公開完了
